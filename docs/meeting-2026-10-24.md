# PROJECT 100X · 제2차 개발 회의록

- 기록일: 2026-10-24
- 상태: 회의 종료 / 9개 안건 확정
- 성격: 제품 설계 결정 사항. 구현 완료나 성능 검증 완료를 의미하지 않음.
- 원칙: 월 호스팅 비용 0원, 기존 가상투자 기록 보호, 독립 검증 우선, 실제 주문 실행 금지.

## 확정 의결

1. **실패 추천 처리 — C**: 실패 원인 분석, 개선안 생성, 기존 전략과 독립 비교 검증 후 개선 반영 검토.
2. **종목 추천 기준 — C**: 시장 상황, 데이터 품질, 전략 검증 성과, 위험 대비 기대수익을 종합 평가.
3. **급락장 대응 — C**: 위험 수준에 따라 신규 추천 제한, 급락장 전략은 별도 검증.
4. **가상투자 검증 기간 — C**: 최소 6~12개월 관찰하되 거래 수와 시장 국면 다양성도 함께 평가.
5. **성과 평가 — C**: 수익률, 최대낙폭(MDD), 손익비, 거래비용, 시장 대비 성과를 종합 평가.
6. **JT AI 전략 개선 — C**: 실패 분석 및 개선안 자동 연구를 지향. 독립 검증에 통과한 안건만 사용자에게 보고하고, **사용자 승인 후 적용**. 무료 환경 제약에 맞춰 단계적 구현.
7. **목표가·손절가 — C**: 변동성, 지지·저항, 시장 상황, 보유기간, 손익비를 종합 평가. 근거 부족 시 추천 보류.
8. **신호 알림 — C**: 정기 보고와 중요 신호 알림 병행. 실시간 알림은 무료 환경에서 기술 검증 후 단계적으로 도입.
9. **추천 종목 수 — C**: 시장 상황에 따라 0~5개. 적합한 종목이 없으면 0개(추천 없음).

## 추가 사용자 요구

- **개발 회의실 UI**: 휴대전화에서 A/B/C 라디오 버튼을 직접 터치하고 ‘선택 확정하기’를 눌러 의결하며 결과를 저장할 수 있도록 앱에 구현할 것.
- 채팅에 표시된 ‘○’ 문자는 실제 터치 버튼이 아니므로, 작동하는 버튼인 것처럼 안내하지 않을 것.
- JT AI 연구 일지: 추천 당시 데이터·근거·목표가·손절가·사후 결과·실패 원인·개선안 및 검증 결과를 기록.

## 후속 개발 우선순위

1. 미국·한국 실제 과거 시세 데이터 수집/검증 경로 설계
2. P0 회귀 테스트 재확인 및 P2 실제 데이터 백테스트 검증
3. JT AI 연구 일지
4. 터치형 개발 회의실
5. 목표가·손절가 산출 및 추천 근거 강화

## 검증 주의

- P2 백테스트 연구실은 스마트폰 화면 표시가 확인되었으나 실제 시장 데이터로 계산 정확성이 검증된 상태는 아님.
- P0 수정 후 20/20 회귀 테스트 통과 여부는 재확인 필요.
- 전략의 예측 우위, 실시간 시세·푸시 알림 구현, 실제 수익성은 검증 또는 구현 완료로 간주하지 않음.
