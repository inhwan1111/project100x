- 목적: JT 연구원 평가·성과 추적·위험 경고·추천 정책 확정

## 당일 개발 성과 및 검증 상태

1. GitHub Actions를 이용한 QQQ 일별 시세 수집 성공: 100거래일, 최신 거래일 2026-10-23. 실제 실행 및 GitHub 파일 확인.
2. 모바일 웹에서 자동 시세 수집 상태 표시 확인.
3. JT 연구원 QQQ 자동 기초 분석(종가, 전일 대비, SMA20·SMA50, 추세) 모바일 표시 확인.
4. 기기별 개인 연구실 이름 설정 기능 코드를 반영했으나 아이폰·갤럭시 실제 작동 검증은 아직 미완료.
5. 기존 6대 전략과 자동 백테스트는 자동 QQQ 데이터에 아직 완전히 연결되지 않음.

## 제5차 회의 의결 사항 (모두 C안)

### 의결 1. JT 연구원 평가 표시: 혼합형
- 종합 평가 점수 0~100점 + A~E 등급 + 데이터 충분성을 함께 표시.
- 점수는 정의된 분석 기준에 대한 평가이지 미래 수익 확률을 뜻하지 않음.
- 데이터 부족·검증 부족을 명확히 표시하고 추천 근거 및 위험 요인 제공.
- 구체적 점수 가중치 및 등급 경계는 추후 검증을 통해 확정.

### 의결 2. 추천 성과 추적: 기간별 종합형
- 단기(1~10거래일), 중기(2주~6개월), 장기(6개월~5년 이상)를 구분.
- 추천 당시 근거·가격·점수와 이후 기간별 수익률, 최대 낙폭(MDD), 손절 기준 및 성공·실패 원인 추적.
- 미도래 평가 기간은 평가 대기, 충분한 데이터가 없으면 평가 불가로 표시.
- JT 연구원은 개선안을 제시할 수 있으나 전략 변경은 총괄 책임자의 승인 필요.

### 의결 3. 시장 위험 경고: 통합형
- 시장 전체 위험도 + 개별 종목 위험도 + 투자 기간별 대응 방안 제시.
- 추세·변동성·거래량·과열/급락 위험 등 확보된 자료를 사용.
- 판단에 필요한 자료가 부족하면 '판단 보류'로 표시.
- 위험 경고는 확정적 가격 예측이나 실제 매매 지시가 아님.

### 의결 4. 종목 추천: 선별 추천형
- 검증 가능한 기준을 통과한 종목만 추천 후보로 제시.
- 추천 후보에 점수·등급, 근거, 적정 관찰/보유 기간, 진입 구간, 목표가, 손절가, 위험 요인, 검증 상태를 표시.
- 기준 통과 종목이 없거나 자료가 불충분하면 추천을 보류하고 관망 사유를 설명.
- 예시 수치와 검증되지 않은 예측은 실제 추천으로 표시하지 않음.

## 유지할 기존 확정 원칙

- 개발 순서 B(자동 데이터 수집·분석) → C(JT 연구원 고도화) → A(UI 개선).
- 미국 시장 우선 확장: QQQ → 미국 ETF·주식 → 한국 시장 → 통합 분석.
- 월 호스팅 비용 0원 우선, 실제 매매가 아닌 가상투자 중심.
- 기존 가상투자·백업 데이터 보존, 개인 데이터의 의도치 않은 혼합 방지.
- 투자 전략 자기 개선은 사전 검증 후 총괄 책임자 승인.
- 이미 확정한 사항은 다음 회의에서 반복 의결하지 않음.

3. JT 평가 점수/등급/데이터 충분성 표시 초안 구현 및 점수 산식 공개.
4. 추천 시점과 사후 성과를 구분하여 가상 추적 기록 구조 설계.
