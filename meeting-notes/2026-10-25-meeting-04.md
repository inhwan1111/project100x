# PROJECT 100X 제4차 개발회의 회의록

- 일자: 2026-10-25
- 참석: 프로젝트 총괄(사용자), AI 개발 파트너(GPT-6)
- 목적: 개발 우선순위 및 데이터 수집·추천 엔진 구현 방향 확정
- 상태: 회의 종료 / 의결 사항 기록

## 의결 사항

1. **개발 우선순위**: B(자동 데이터 수집 및 분석 엔진) → C(JT 연구원 고도화) → A(사용자 인터페이스 개선).
2. **JT 연구원 투자 기간**: C(통합형). 단기(1~10거래일), 중기(2주~6개월), 장기(6개월~5년 이상) 연구를 구분하고 성과를 독립적으로 검증.
3. **종목 추천 방식**: C(혼합형). 종합 점수 평가 + 기존 6대 전략 합의 + 위험관리 검증을 결합. 점수 배점은 초기 가설이며 실제 예측력 검증 전에는 확정 성능으로 간주하지 않음.
4. **자기 개선 방식**: 기존 결정 유지(검증 후 개선형). 추천 결과와 실패 원인 기록, 실험·미사용 데이터·가상투자 검증 후 변경안 제시, 실제 전략 변경은 총괄 책임자 승인 필요. 이미 의결한 사항이므로 재의결하지 않음.
5. **자동 데이터 수집 시장 확장 순서**: D(미국 시장 완성 후 한국 시장 확장). QQQ 자동 시세 수집 → 미국 주식·ETF 확대 → 한국 주식시장 연결 → 미국·한국 통합 분석 엔진.

## 지속 운영 원칙

- 월 호스팅 비용 **0원** 우선.
- 실제 매매가 아닌 **가상투자**를 우선 운영.
- 기존 가상투자 데이터 및 백업 기록 보존.
- 검증되지 않은 분석 결과를 실제 예측 성능으로 표현하지 않음.
- 회의에서는 이미 확정된 안건을 반복 질문하지 않고, 신규 문제와 개발 검증 결과 중심으로 논의.

## 다음 개발 작업

1. QQQ 자동 시세 수집을 정기 실행하도록 구현.
2. 데이터 갱신 여부, 누락 및 오류 탐지 확인.
3. 기존 가상투자 기록 보존을 확인한 후 미국 종목으로 확장.
4. 이후 JT 연구원의 추천 근거·보유기간·목표가·손절가 분석을 검증 가능한 형태로 고도화.

## 별도 미해결 사항

- 홈 화면 '연구실 바로가기' 카드가 최상단에 표시되는지 실제 기기에서 최종 확인 필요.
- 이 회의록의 '확정'은 설계 결정이며, 기능 개발 완료를 의미하지 않음.
